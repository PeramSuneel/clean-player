Clean Player - official Material icons (outlined, 24dp, white)
Source: github.com/google/material-design-icons (Apache 2.0), converted from the official SVG files to Android vector drawables.
Copy all pl_ic_*.xml files into: app/src/main/res/drawable/
Files are prefixed pl_ so they never replace your existing icons. Icons: arrow_back, cast, volume_up, volume_off, screen_rotation, audiotrack, closed_caption, speed,
picture_in_picture_alt, playlist_play, flip, repeat, repeat_one, lock, lock_open, fast_rewind,
fast_forward, skip_previous, skip_next, pause, play_arrow, replay, aspect_ratio
