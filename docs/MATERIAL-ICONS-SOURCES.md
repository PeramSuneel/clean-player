# Material Icons used by Clean Player V3

The V3 player controls use the official Android VectorDrawable XML exports from Google's [google/material-design-icons](https://github.com/google/material-design-icons) repository, using the Outlined style (`materialiconsoutlined/black/res/drawable/outline_*_24.xml`). The vector geometry is copied from those upstream resources; no icon path is hand-drawn.

The Cast action remains hidden because Google Cast SDK integration is not part of this build; therefore its icon is not displayed.
